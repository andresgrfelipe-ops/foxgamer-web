# Imágenes Apple verificadas

82 referencias, 246 variantes y 74 archivos oficiales. Fecha: 2026-09-19.

Las imágenes son referencias del fabricante, no fotos de la unidad. Color, accesorios, estado y disponibilidad se confirman por separado. Los archivos se alojan localmente y cada registro conserva fuente, modelo y SHA-256 en data/store.json.

Las imágenes compartidas se limitan a capacidades/etiquetas del mismo iPhone y a las referencias documentadas de iPad Air 13 M3 y Watch Series 11 que Apple ilustra con el mismo recurso. Las guardas rechazan cruces entre otros modelos y comprueban cada huella.

Netlify ejecuta npm run build y npm test antes de publicar desde la raíz. data/store.json y scripts/storefront.mjs son las fuentes; el despliegue regenera todas las fichas HTML.
