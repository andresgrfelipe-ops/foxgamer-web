Privacidad y uso de datos

Datos para tu pedido

El carrito solicita nombre, teléfono, ciudad y, para envío a domicilio, dirección. Estos datos se incluyen en el mensaje que decides enviar a FOX GAMER por WhatsApp para gestionar la compra y la entrega.

Utilizamos los datos del pedido para la atención, facturación, envío y servicio posventa. Los datos necesarios para la entrega se facilitan al servicio encargado de tu envío.

Almacenamiento en tu dispositivo

El carrito guarda los artículos seleccionados en tu navegador para que puedas continuar la compra. Los datos de contacto que escribes permanecen en la página mientras preparas el mensaje y no se guardan de forma persistente en el navegador.

Medición de interés

Registramos clics de compra mediante Netlify: tipo de acción, referencia de producto y página. Esta medición no envía el nombre, teléfono, dirección, texto del pedido ni un identificador de cliente. El proveedor de alojamiento puede procesar información técnica de la conexión.

Servicios externos

Al abrir WhatsApp, Instagram, Google Maps o un servicio de financiación, se aplican las políticas de ese proveedor. El carrito no solicita contraseñas, datos de tarjetas ni códigos de verificación.

Atención sobre tus datos

Puedes solicitar información, corrección o eliminación de tus datos mediante el WhatsApp oficial de FOX GAMER. Identifica tu solicitud y el pedido relacionado para que podamos atenderla.
